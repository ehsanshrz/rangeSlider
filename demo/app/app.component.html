RangeSlider base on NpnSlider

A Multi Range Slider Component — Sample Gallery
GitHub

NpnSlider is a multi range slider component using Angular. Below are many usage samples demonstrating its features: multi range, single range, steps, disabled, hidden tooltips, and more.

1. Basic Multi-Range Slider

Selected: {{currentValues | json}}

{{codeSnippetText}}
```html <npn-slider [min]="2006" [max]="2020" (onChange)="onSliderChange($event)"></npn-slider> ```

2. Single Range Slider

{{codeSnippetText}}
```html <npn-slider [multiRange]="false" [min]="2006" [max]="2020" [minSelected]="2010"></npn-slider> ```

Use [multiRange]="false" for a single-handle slider.

3. Price Range Slider ($0 – $1000)

Price: ${{priceValues[0]}} – ${{priceValues[1]}}

{{codeSnippetText}}
```html <npn-slider [min]="0" [max]="1000" [minSelected]="200" [maxSelected]="800" [step]="50" (onChange)="onPriceChange($event)"></npn-slider> ```

4. Temperature Range (−20°C – 50°C)

Temperature: {{tempValues[0]}}°C – {{tempValues[1]}}°C

Range: {{percentValues[0]}}% – {{percentValues[1]}}%
